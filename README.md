# Front Page Creator

A static mini GUI app for generating academic front pages / cover pages.

## Features
- Fixed university preset
- Student, course, and teacher fields
- Logo upload
- Live preview
- Export as PNG or PDF
- Works in browser
- Easy to host on GitHub Pages

## Run locally
Just open `index.html` in a browser.

## Host on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`.
3. Enable GitHub Pages from repository settings.
4. Open the Pages link.

## Notes
This app uses CDN libraries:
- html2canvas
- jsPDF

If you want it to work fully offline, the libraries can be bundled into the repo later.
